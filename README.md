# João D Studio

Site/portfólio de landing pages — Next.js 15 (App Router), Tailwind CSS e GSAP.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000

> No Windows PowerShell, se o `npm` for bloqueado, use `npm.cmd`.

## Estrutura

- `app/` — layout, página e estilos globais
- `components/` — seções do site, animações (`Motion.js`) e configurações (`config.js`)

## Publicação

Deploy na Vercel, conectado a este repositório (cada push na `main` publica automaticamente).
